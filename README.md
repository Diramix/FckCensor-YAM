# FckCensor YAM

*Плагин для Яндекс Станции, который заменяет треки с цензурой на их версии без цензуры в Яндекс Музыке.*

## Трек-лист

**[Open track list](https://nm.diram1x.ru/fckcensor-next)**

## Установка

> Перед установкой необходимо поставить пакетный менеджер YAM на вашу колонку и ПК. [Подробнее](https://github.com/nyakokitsu/yam)

1. Скачайте последний [релиз](https://github.com/Diramix/FckCensor-YAM/releases/latest).
2. Пропишите команду `yam install <путь к скачанному файлу>`.
3. Запустите сервис командой `yam service enable fckcensor`.
4. Готово!
